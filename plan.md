1. CORE DESIGN STANDARD
==================================================

Create a premium, modern, attractive, feature-rich, high-performance, reliable, and conversion-focused website.

The website must:

- Have a unique visual identity based on the client’s industry.
- Look human-designed, polished, premium, and business-specific.
- Avoid generic templates, repetitive layouts, excessive gradients, random glass effects, and unnecessary decorations.
- Use consistent typography, spacing, colour, border radius, shadows, icons, and animation styles.
- Maintain a strong visual hierarchy throughout the website.
- Use high-quality, business-relevant content and media.
- Avoid excessive empty space and extremely large headings.
- Avoid overcrowding the interface.
- Present enough useful content to build trust and explain the business clearly.
- Include a professional header, footer, call-to-action sections, contact information, and conversion elements.
- Use the client’s actual logo without modifying, stretching, recolouring, or recreating it.
- Use meaningful icons instead of emojis.
- Ensure every page has a premium, cohesive visual style.

Do not create a simple website. The result must feel like a high-value custom website suitable for a professional client.

3. TAMIL AND ENGLISH LANGUAGE SUPPORT
==================================================

The entire website must support both English and Tamil.

Language functionality must:

- Add a clearly visible English | தமிழ் language switcher in the header.
- Translate all pages and visible content—not only the homepage.
- Translate navigation, headings, paragraphs, buttons, forms, validation messages, chatbot content, FAQ, footer, legal pages, alerts, and success messages.
- Keep both languages professional and natural.
- Avoid literal or machine-like Tamil translations.
- Store language content separately using a scalable translation structure.
- Remember the selected language using localStorage, cookies, or the framework’s localization method.
- Default to English unless the project requirement specifies Tamil.
- Change the page language without breaking the layout.
- Set the correct HTML lang attribute.
- Use Unicode-compatible fonts with excellent Tamil readability.
- Ensure long Tamil text does not overflow cards, buttons, or mobile layouts.
- Provide localized page titles, descriptions, Open Graph data, and SEO metadata where practical.
- If separate language URLs are used, implement hreflang and canonical tags correctly.

Do not leave any important content untranslated.

- Use the client’s branding and business name.
- Support Tamil and English.

- Be keyboard accessible and closable.
- Avoid blocking important content.

Write client-specific answers for every question in both Tamil and English.
